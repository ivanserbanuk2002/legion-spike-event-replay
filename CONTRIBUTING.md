# Contributing

Use Node 20 or newer. Run `npm ci`, `npm run typecheck`, then `npm test`.
Add a small synthetic journal when changing validation or replay behavior.
Preserve file order, event identity and callback error propagation.
Keep runtime dependencies at zero. Broker transports belong in a separate adapter.
Use the bug report template for reproducible input; redact account data and secrets.
Small parser fixes, offline tests and clearer usage examples are welcome.
